# Run Log

* **מה עבד?**
  * מעבר לתיקייה `event-photo-capstone` והתקנת החבילות בהצלחה בעזרת `npm install`.
  * הרצת השרת באמצעות `npm run dev`.
  * בדיקת נקודות הקצה של ה-API והגשת טופס בחירת תמונות בהצלחה ב-PowerShell בעזרת `Invoke-RestMethod`.

* **מה לא עבד?**
  * הרצת `npm install` בתיקייה הראשית נכשלה כי קובץ `package.json` נמצא בתוך תיקיית המשנה.
  * הרצת פקודת `curl` נכשלה ב-PowerShell בגלל תווים מיוחדים וסוגריים מרובעים ב-JSON.

* **מה היה צריך לשנות/לתקן כדי שיעבוד?**
  * ניווט לתיקיית הפרויקט המדויקת `event-photo-capstone`.
  * שימוש בפקודת `Invoke-RestMethod` עם המשתנה `$body` ב-PowerShell לשליחת הבקשה בצורה נקייה 
  ותקינה.


  * **מה עבד?**
  * הרצת בדיקות המערכת באמצעות `npm test` ו-`npm run typecheck`.
  * הרצת השרת במצב פיתוח באמצעות `npm run dev`.

* **מה לא עבד?**
  * (רשמי כאן אם הייתה שגיאה כלשהי בטסטים או בטיפוסים, ואם הכל עבר חלק – צייני שלא היו שגיאות).

* **מה אומת, ומה לא?**
  * אומת שתקינות הקוד וטיפוסי ה-TypeScript עוברים ללא שגיאות, ושהבדיקות האוטומטיות רצות ומאמתות את הפונקציונליות של המערכת.
